# API ข้อมูลส่วนตัวสำหรับ SENA Care

> แพ็กนี้ถูกแทนที่แล้ว: SDL_school มี endpoint ทางการ `/students/{code}/profile` ตั้งแต่ commit `f6f0c80` ส่วน SENA Care ใช้ endpoint ใหม่นี้แล้ว จึงไม่ต้องติดตั้งแพ็กแบบ `include_personal` ด้านล่าง

API จริงยังไม่ส่งข้อมูลส่วนตัว แพ็กนี้ต้องติดตั้งบนโฮสต์ SDL_school ก่อนจึงจะแสดงข้อมูลใน SENA Care ได้ ไม่ต้องเปลี่ยนตารางหรือข้อมูลฐานข้อมูล

อัปโหลดทั้งโฟลเดอร์ไปนอก public web root แล้วรัน:

```sh
php install.php /absolute/path/to/SDL_school
cd /absolute/path/to/SDL_school/laravel-app
php artisan optimize:clear
```

ตัวติดตั้งตรวจตำแหน่งแก้ไข สำรองไฟล์ต้นฉบับไว้นอก web root และตรวจ PHP syntax ก่อนแทนที่ รองรับการติดตั้งซ้ำ ย้อนคืนได้จากไฟล์สำรองที่แสดงหลังติดตั้ง

ส่งเพิ่มเฉพาะ GET `/students/{code}?include_personal=1`: วันเกิด เพศ อาชีพ เบอร์โทร อีเมลแบบปิดบางส่วนตามต้นทาง และชื่อ/ความสัมพันธ์/อาชีพของบิดา มารดา ผู้ปกครองที่มีข้อมูล ไม่ส่งเลขบัตรประชาชนทั้งเต็มและปิดบางส่วน ไม่ส่ง raw payload รายชื่อ `/students` ยังคงรูปแบบเดิมและใช้การยืนยัน token/ตรวจสิทธิ์อำเภอเดิม

SENA Care เรียกจาก backend หลังตรวจสิทธิ์ผู้เรียน มี timeout 5 วินาทีและแสดงข้อมูลเดิมเมื่อ API ไม่พร้อม ข้อมูลจาก API ใช้แสดงผลเท่านั้น ไม่เขียนทับข้อมูลที่บันทึกใน SENA Care
